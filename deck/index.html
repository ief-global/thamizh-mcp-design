The problem

AI speaks Tamil fluently.
It gets Tamil grammar wrong — confidently.

மரம் + த்து + இல்
wrong — the சாரியை is அத்து
Pure-Tamil word for ஜன்னல்?
“வளி மறை” · “வாதில்”
these words do not exist — invented on the spot

Both recorded in our own A/B tests, asked in Tamil, with no tool attached.

The second box is the killer. Not a wrong answer picked from real options — fabricated Tamil, delivered fluently. That is the failure mode this project exists to remove. Correct answer for ஜன்னல் is சாளரம்.

One root, many surfaces

Past

இறந்தகாலம் · படர்க்கை ஆண்பால் ஒருமை
Present
வருகிறான் → வா + கிறு + ஆன்
நிகழ்காலம் · கிறு = நிகழ்கால இடைநிலை

The surface says வரு-. The root is வா. A pattern-matcher answers வரு; this knows the paradigm.

Suppletive stems are exactly where naive tools and LLMs fail. Good place to invite a word from the audience.

How it works

One engine, many front doors

word → normalize → knowledge store (cached? serve with provenance) → miss: source adapters anchors ThamizhiMorph FST · Tholkappiyam rule table · கலைச்சொல் evolving Tamil Wiktionary · தனித்தமிழ் lists → decoder (FST tags → உறுப்பு · case → வேற்றுமை · authority tagger) → merge + write back → heads: MCP tools | REST + web | CLI

We wrap ThamizhiMorph (Sarveswaran, Dias & Butt 2021) — 93.3% coverage and 97.9% correct lemmas on a 612-word corpus — rather than rebuild it.

Key point for technical listeners: Tamil words are GENERATED, not listed. One root yields thousands of forms, so no dictionary can enumerate them — that's why the core is a rule engine, not a database.
Who it is for

Four audiences, one engine

  • App developers — a Tamil grammar helper for school students becomes one API call; no Tamil-grammar expertise required
  • Teachers & students — answers that carry their authority, so they can be verified, not merely trusted
  • Scholars — a machine-readable, citable encoding of classical grammar rules
  • The language itself — every analysis is logged as verified data, seeding the corpus future Tamil models will need

Tamil is “low-resource” because it lacks data. This creates data by being used.

The last bullet is the long game — the flywheel. Usage → gold corpus → better Tamil models → more usage.
