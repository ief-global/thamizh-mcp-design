Draft and sent letters to the people and institutions whose work this project stands on. Kept in git
because **the licence position on a source is part of its provenance**, and a future reader needs to
know not just what terms apply but what we asked and what we were told. Not every letter here asks
for a permission; one of them exists to credit work properly and offer something back.

## Conventions

- **Record replies here**, next to the letter, including refusals. A "no" is as useful to a future
  maintainer as a "yes", and stops the same request being made twice.
- **When terms are granted or clarified, update `data/PINS.md` and `LICENSING.md` in the code repo**
  and log a decision. The letter is evidence; those files are authority.
- **A letter that asks for something should also give something.** The Sarveswaran letter leads with
  an offer (hand-checked analyser misses) and the TVA letter returns a correction we found in their
  course books. Both are true and both were found by doing the work, which is the only kind of
  offer worth making.
- **Never claim a licence we have not been granted in writing.** This folder exists partly because
  we shipped an unsubstantiated "MIT" claim for the S2PT word lists until 2026-08-08 (D-017).
